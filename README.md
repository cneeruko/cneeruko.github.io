# Cneeruko Website

A simple, formal, GitHub Pages-ready landing page for the Cneeruko brand.

## Local preview

Open `index.html` directly in a browser, or serve the folder with any static file server.

## Publish to GitHub Pages

1. Push this repository to GitHub.
2. Enable GitHub Pages in the repository settings.
3. Use the root of the repository as the publishing source.

## Customize

- Update the hero copy in `index.html`
- Replace the contact placeholder with real details
- Adjust the color palette in `styles.css`
